- 353: `need at least 3 points`; all 353 are `*.struts.vect`.

Among the 2544 comment failures are ordinary `.vect`, `.atstart.vect` and `.final.vect` centerline candidates,
plus `.dlen.vect`/`.dVdt.vect` diagnostic products. v0.2.4 therefore does two separate things: supports comments
for real centerlines and excludes the diagnostic products before centerline parsing.
