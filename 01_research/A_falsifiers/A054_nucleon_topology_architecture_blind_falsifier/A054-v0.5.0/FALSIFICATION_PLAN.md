# A054-v0.5.0 falsification plan

The decisive question is not whether an arbitrary relaxation can make a pretty knot. It is whether one globally frozen, target-free state selector maps independently sourced representatives of the same topology to the same stationary and stable endpoint.

Scientific FAIL never aborts later diagnostics. Infrastructure/provenance failures remain fail-closed.

The primary negative outcomes are: selector fails to reach stationarity; providers converge to different endpoints; stationary endpoint is a saddle; ringdown is unbounded; or topology/clearance proxy is violated.
