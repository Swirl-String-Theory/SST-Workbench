# SST Fermat pybind research v0.6.0

Standalone Python + C++17/pybind11 research harness. It does **not** import, modify, or patch SSTcore.

This release turns the v0.3 softening scan into a candidate-certification pipeline for the fixed four-knot matrix

\[
0_1,\qquad 3_1,\qquad 4_1,\qquad 5_2.
\]

The bundled centerlines are reconstructed from the uploaded `ideal_favorites.txt` Fourier database. The package remains **Research Track** software: it resolves numerical stationary structures and separately certifies convergence-qualified branches; it does not establish a physical electron model or a global photon sphere.

## v0.6.0 scope: full Fermat rays and monodromy

v0.6.0 is the first release that advances beyond local radial candidates. It integrates complete rays in the full three-dimensional, non-axisymmetric Fermat metric generated by the same regularized Biot--Savart field used by v0.4.x.

For the clock-only ansatz,

\[
g^{F}_{ij}(\mathbf x)=S(\mathbf x)^{-2}\delta_{ij},
\qquad
S(\mathbf x)=\sqrt{1-\lVert\boldsymbol\beta(\mathbf x)\rVert^2},
\]

and, using Euclidean arclength \(\ell\) with unit tangent \(\mathbf t\), the ray system is

\[
\frac{d\mathbf x}{d\ell}=\mathbf t,
\qquad
\frac{d\mathbf t}{d\ell}
=-\frac{(I-\mathbf t\mathbf t^{\mathsf T})\nabla S}{S}.
\]

The analytic Biot--Savart Jacobian supplies

\[
\nabla S=-\frac{J_{\beta}^{\mathsf T}\boldsymbol\beta}{S}.
\]

## New in v0.6.0

1. **Full 3-D Fermat ray integration** in `fermat_ext/geodesic.py`, using fixed-step RK4, tangent renormalization, optical-length accumulation, real-clock-domain termination, and backend provenance.

2. **Five-variable closed-orbit shooting.** A local `RESOLVED_LOCAL_MINIMUM` seed is promoted to a full ray seed. The solver varies two transverse starting-position coordinates, two direction tilts, and the orbit period using damped Gauss--Newton iteration.

3. **Two-axis orbit convergence.** `certify_global_closed_orbit` requires:

   - a three-level ray-step ladder at each centerline discretization; and
   - agreement across a three-level centerline ladder.

   A single successful shot is only `RESOLVED_CLOSED_ORBIT`. The stronger flag

   ```json
   "global_closed_orbit_certified": true
   ```

   is emitted only after both convergence axes pass.

4. **Reduced monodromy diagnostics.** A centered finite-difference flow map is projected onto a four-dimensional transverse basis. The output includes the reduced matrix, eigenvalues, spectral radius, determinant, unit-circle deviation, and reciprocal-pairing residual.

5. **Perturbation-convergence gate for monodromy.** The map is recomputed at three finite-difference scales. `monodromy_certified` additionally requires a globally certified orbit.

6. **New command-line tools:**

   ```text
   run_geodesic_shooting.py
   run_orbit_convergence.py
   run_monodromy.py
   run_monodromy_smoke.py
   run_global_orbit_campaign.py
   ```

7. **New Windows launchers:**

   ```text
   START_V060_GLOBAL_ORBIT_SMOKE.bat
   START_V060_GLOBAL_ORBIT_CAMPAIGN.bat
   ```

   The previous local-candidate campaign remains available as `START_V060_LOCAL_CAMPAIGN.bat`.

## Scientific gates

The hierarchy in v0.6.0 is deliberately strict:

\[
\text{local radial minimum}
\not\Rightarrow
\text{resolved closed ray}
\not\Rightarrow
\text{convergence-certified orbit}
\not\Rightarrow
\text{QSM pole}.
\]

The package may therefore complete successfully while reporting zero certified closed orbits. That is a valid negative result, not a software failure. Every v0.6.0 output keeps

```json
"qsm_certified": false
```

because complex-frequency wave resonances are outside this release.

## Kernel scope

The full three-dimensional knot field still uses the regularized midpoint Rosenhead kernel

\[
\boldsymbol\beta(\mathbf x)
=
\frac{\beta_0}{2}
\sum_i
\frac{
\Delta\boldsymbol\ell_i\times
(\mathbf x-\mathbf x_{i+1/2})
}{
\left(\lVert\mathbf x-\mathbf x_{i+1/2}\rVert^2+\epsilon^2\right)^{3/2}
}.
\]

Its analytic spatial derivative is computed from

\[
\frac{\partial}{\partial x_j}
\left(
\frac{r_k}{Q^{3/2}}
\right)
=
\frac{\delta_{kj}}{Q^{3/2}}
-
\frac{3r_kr_j}{Q^{5/2}},
\qquad
Q=\lVert\mathbf r\rVert^2+\epsilon^2.
\]

Rankine and Lamb--Oseen remain one-dimensional comparison profiles only; they are not silently substituted into the full three-dimensional knot solver.

## Epistemic status labels

A root can be labelled:

```text
RESOLVED_LOCAL_MINIMUM
LOCAL_MAXIMUM
DEGENERATE_STATIONARY_POINT
GLOBAL_CAUSTIC_REGIME
NOT_CONVERGED
```

`RESOLVED_LOCAL_MINIMUM` means that a stationary radial minimum was solved numerically in one transported normal plane. It does **not** mean that a closed Fermat geodesic exists in the full non-axisymmetric metric.

Local-candidate outputs preserve:

```json
"global_closed_orbit_certified": false,
"qsm_certified": false
```

Only the two-axis global convergence gate may set `global_closed_orbit_certified=true`. All v0.6.0 outputs keep `qsm_certified=false`. The reach value remains an approximate diagnostic, not a rigorous Ridgerunner/reach certificate.

## Performance notes

The native Jacobian kernel performs substantially more arithmetic than the field-only kernel. Candidate discovery batches all radial probes, and bisection refines all active brackets together. Nevertheless, high-resolution runs with \(N=32768\), many stations, and many angular sectors can require significant RAM and runtime.

Recommended sequence: use `START_V060_LOCAL_CAMPAIGN.bat`. It encodes the audited order, writes per-step logs, and resumes after interruption.

## What v0.6.0 can and cannot conclude

v0.6.0 can distinguish among:

```text
local radial seed does not produce a closed full ray
single-resolution closed ray resolves but fails convergence
closed ray passes integration and centerline convergence
monodromy remains perturbation-sensitive
reduced monodromy passes its finite-difference gate
```

It still cannot establish a quasinormal swirl mode. That requires a wave or complex-frequency boundary-value solver and a stable complex pole under absorber, domain, and resolution variation.
