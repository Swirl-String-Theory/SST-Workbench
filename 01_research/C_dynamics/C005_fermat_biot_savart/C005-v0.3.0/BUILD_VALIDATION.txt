Environment limitation
----------------------
The artifact environment does not contain pybind11, so the v0.3.0 native
Python extension was not built here. The independent C++17 kernel and the
Python fallback were validated. Rebuild the changed binding on Windows:

  python -m fermat_ext.build_ext_if_needed --force --strict
  python run_all_checks.py --out-dir audit_out_native --no-auto-build --require-native

A v0.2.0 .pyd must not be reused because v0.3.0 adds the explicit
kernel_model binding argument.
