# First executable follow-up

Proposed v0.2.2: resource-bounded static core-seed preflight before any dynamics campaign.

Inputs already available: authentic PTSA coordinates, Gaussian initializer in both backends, curvature/chart and grid-screen calculations, full Euler source. Add preflight for nonlocal tube overlap, projection-induced field change, periodic-image contamination and byte/work estimates. Use a common normalization and compute a preregistered grid/core/remesh refinement plan; refuse full evolution if the joint admission criteria fail or estimated resources exceed a declared cap. This can strengthen producer admission; it cannot produce a material-phase branch verdict.

Required physical architecture for v0.3.0: specify the observable phase of a non-axisymmetric active core perturbation, separate it from material-label gauge and conventional Kelvin core/twist modes, demonstrate independently excited degrees of freedom, extract a moving centerline and material frame from the Euler field, and verify gauge/SO(3)/twist-holonomy relationships. A tube with an axisymmetric profile does not by itself provide a measurable azimuthal phase. This definition/producer qualification is the missing scientific dependency, not a missing linear-dispersion fitting function.

The current sampling/curvature estimate N>=252 is only a necessary local screen at the present box and geometry scale. It omits nonlocal embedding and box convergence and is not authorization to run a large production campaign or an estimate of adequate mode resolution. Longer windows also require energy/topology/circulation controls and a stationary base or Floquet treatment.
