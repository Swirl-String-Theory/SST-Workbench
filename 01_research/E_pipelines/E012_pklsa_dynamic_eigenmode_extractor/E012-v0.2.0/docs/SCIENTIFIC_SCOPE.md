# Scientific scope — E012 v0.2.0

E012-v0.2.0 is a qualification bridge, not a particle-identification module.

It may establish:

- E011 multi-provider provenance for one topology;
- a same-generator C006 RPO qualification result for each provider;
- a resolution-stable Kelvin eigenbranch whose identity is supported by complex eigenvector overlap;
- cross-provider agreement of independently qualified dimensionless mode samples.

It may not infer:

- that the branch is a photon;
- that an accepted RPO is a true Floquet spectrum;
- a physical source diameter or circulation from A044 targets;
- an energy mapping from GRB 221009A;
- an LIV scale by fitting the downstream observational window.

The physical scale contract remains a separate, explicit and target-independent gate.
