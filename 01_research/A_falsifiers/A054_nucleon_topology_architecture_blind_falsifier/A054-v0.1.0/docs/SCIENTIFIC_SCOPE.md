# Scientific scope

Primary question: does collective three-component architecture add reproducible stabilization, compactness or far-field isotropy beyond matched unlinked controls under one common finite-core filament operator?

The preregistered reveal contrasts are:

- Triple-Gear skeleton effect for unknotted components: `P_B - C0`.
- Triple-Gear architecture effect at fixed twist-knot content: `P_C - P_A`.
- Component-knotting effect inside Triple-Gear architecture: `P_C - P_B`.
- Borromean-skeleton effect for unknotted components: `N_B - C0`.
- Borromean-skeleton architecture effect at fixed twist-knot content: `N_C - N_A`.
- Component-knotting effect inside Borromean skeleton: `N_C - N_B`.

The symbols are reveal-only. Blind analysis sees anonymous IDs.

This release does **not** fit or test proton/neutron masses, charge, atomic binding, Bohr radius, Coulomb closure, gravity closure, or a full Kelvin/Floquet spectrum. Those are downstream gates. In particular, `STATIC_READY` is not `DYNAMICS_READY`.

## Orientation / circulation control

Every candidate is evaluated under four relative circulation-sign patterns modulo global reversal, crossed with both per-component and fixed-total normalization. Source-native component orientation is never mirrored or selected after observing the result in v0.1.0.
