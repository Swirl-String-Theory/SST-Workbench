\section{Identification}
A058 v0.2.10 is a single-trefoil, eight-slider, default-relative KnotPlot response experiment with matched iteration-budget observations with staged horizons instead of claiming convergence. It is pinned to SST Falsifier Framework v1.0.8.
% SST-REPORT-SECTION:QUESTION
\section{Question}
Which anonymous GUI slider parameters alter the finite-time embedded geometry and bead parametrization at identical observation counts relative to their sector-context runtime default values?
% SST-REPORT-SECTION:HYPOTHESES
\section{Hypotheses}
The frozen science contract registers the global no-effect null and measurable-response alternative.
% SST-REPORT-SECTION:ASSUMPTIONS
\section{Assumptions}
The actual executable parameter dumps define numerical defaults. Sliders may be conditional on an enabled GUI sector and therefore need not appear in the bare reset-all dump. The user-requested dynamics is damped with collision avoidance; the original catalogue embedding itself is NOT an admissible default-safe seed. A once-only geometric safe-seed preparation uses \texttt{fitto mindist} at $1.05$ times the measured reset-default close threshold. This normalizes the absolute embedding scale but does not modify any dynamics parameter. All conditions reuse the same saved seed without per-condition fitting, refining, or setting close/max-dr/stusplit/time increment.
% SST-REPORT-SECTION:SYMBOLS
\section{Symbols}
Primary quantities are multiplier $m$, $x=\log_2m$, normalized shape distance $D_{\rm shape}$, edge-spacing coefficient of variation, and registered iteration checkpoint $N$.
% SST-REPORT-SECTION:EQUATIONS
\section{Equations}
Registered equations and dimensional checks are generated from the frozen science contract.
% SST-REPORT-SECTION:ALGORITHM
\section{Algorithm}
Install calibration verifies eight setters in six enabled sector contexts. It normalizes the raw catalogue trefoil once to a registered safe geometry scale, exports exactly one ASCII trefoil, reloads that exported geometry, and checks safety before and after a single dynamics step. Every scientific condition then loads precisely that same immutable seed. All eight axes now require runtime numeric getter evidence using the six-decimal display precision of the KnotPlot parameter dump, including the separately resolved S3 getter alias. The registered reset-default S3=1.40 and R2 reset OFF are preserved (enabled reference ON). This certifies rounded displayed values, not the exact internal FP64 parameter state. The production campaign contains six sector-on references, one separate sector-off R2 activation control, and eight one-slider-at-a-time sweeps. Each scientific condition is advanced to preregistered common observation checkpoints using incremental $\mathrm{go}$ commands: BASIC at 32, 128, 512; extended tier additionally at 2048; heavy tier additionally at 8192 and 32768. The heavy tier is restricted to at most 31 automatically preselected conditions from valid earlier results, including independently hash-bound qualification overlays of legacy runs if explicitly imported. Each budget is a finite-time observation horizon, not an attractor or convergence certification.

% SST-REPORT-SECTION:SOURCES
\section{Sources}
One runtime-identified KnotPlot executable and one immutable, preconditioned 300-bead trefoil ASCII seed (SHA-256 committed in the acquisition manifest) define the simulation source family. Conditions are perturbations, not independent replicates.
% SST-REPORT-SECTION:GATES
\section{Gates}
G0--G9 retain Framework-v1.0.8 lane semantics. Numerical failures are recorded and the campaign continues where possible so diagnostic structure is retained.
% SST-REPORT-SECTION:NUMERICS
\section{Numerics}
Positive multipliers are $2^{k/4}$, $k=-16,\ldots,16$, with a separate zero endpoint. BASIC executes 512, 2048 executes 2048, and the selected heavy lane executes 32768 matched go iterations; checkpoints are at preregistered counts, not a claim of stability.
% SST-REPORT-SECTION:BACKENDS

Python/NumPy FP64 is the reference analysis. C++17/pybind11 FP64 certifies registered scalar coordinate metrics.
% SST-REPORT-SECTION:BLINDNESS
\section{Blindness}
Public analysis uses anonymous slider IDs S0--S7 and reference IDs R0--R5. GUI names and command mappings reside in the private reveal domain. One additional R2-OFF activation contrast is separately registered and is not pooled with the multiplier responses.
% SST-REPORT-SECTION:STATISTICS
\section{Statistics}
Quadratic fits in $x=\log_2m$ are descriptive finite-time fits only. Exact-zero endpoints are excluded from log fits. The primary response measures are final shape, scale-free scalar geometry, bead-spacing variation, and matched-iteration horizon. The R2 ON/OFF contrast at identical numeric slider defaults is analyzed separately.

% SST-REPORT-SECTION:INTERPRETATION
\section{Interpretation}
A slider may affect parametrization or convergence time without selecting a different final embedded curve. Conversely, persistent final-shape changes identify a geometry-selecting numerical control in this KnotPlot model. One anonymous lane is explicitly interpreted as a compatibility test because the KnotPlot GUI advises a different damping regime for that force than the user-requested baseline. The findings are conditional on the explicitly normalized common seed scale; changing that seed scale could change forces and the selected attractor. None of these outcomes establishes physical vortex stability by itself.
