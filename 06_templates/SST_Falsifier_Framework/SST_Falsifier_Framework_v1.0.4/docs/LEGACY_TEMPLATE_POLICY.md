# Legacy template policy

For new SST falsifiers, the following templates are superseded by `SST_Falsifier_Framework_v1.0.4`:

- `SST_Blind_MultiLibrary_Falsifier_Template_v0.1.0`
- `SST_cpp_pybind_audit_template`
- `SST_GPU_SYCL_DPC_audit_template`

Do not delete historical copies: old falsifier releases may depend on them for reproducibility. Do not use them to start new falsifiers.
