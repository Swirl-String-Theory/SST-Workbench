# Preregistration — A043 v0.2.0 PKLSA gate

Primary population: all 48 PKLSA v0.1.1 `knot_3.1` variants.

Primary null-like operational outcome: no single geometry exhibits a numerically valid, resolution-consistent finite-window BKM candidate under the preregistered fit.

Escalation requires, for one and the same anonymous geometry:

- numerical validity at every contributing replay;
- late-window inverse-vorticity fit candidate at >=3 distinct N;
- `R^2 >= 0.98` within each contributing fit;
- extrapolated `T*` in `(T_end, 1.5 T_end]`;
- relative spread of the contributing `T*` values < 10%.

Different PKLSA variants may never be pooled to satisfy the >=3 replay requirement.

The v0.2.0 PKLSA screen is a population screen, not a theorem and not an independent-replication study.
