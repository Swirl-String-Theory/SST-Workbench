# Conclusions status — package v0.1.0

This file records what the package architecture permits one to conclude, not a claim that a user's future native/full campaign has already passed.

- **[IMPLEMENTED]** The experimental Rankine/Kelvin dispersion can be reproduced independently of SST fitting.
- **[IMPLEMENTED]** C++/Python parity is a hard gate during normal native runs.
- **[IMPLEMENTED]** Ring curvature and trefoil frozen-local spectra are kept separate from true Floquet claims.
- **[IMPLEMENTED]** A true relative monodromy is scientifically locked unless an RPO closes.
- **[IMPLEMENTED]** 4-wave and 6-wave resonances are both searched blindly from numerical mode frequencies.
- **[IMPLEMENTED]** Higher-order phase coherence is measurable through normalized 4-wave/6-wave correlators.
- **[IMPLEMENTED]** Broadband transfer and timescale separation are reported without relabelling an unforced finite run as stationary turbulence.
- **[IMPLEMENTED]** The four mirror/circulation configurations can be compared under identical numerical settings.
- **[IMPLEMENTED]** The core package is target-blind with respect to an explicit fine-structure numerical benchmark.

A physically stronger next version would replace or supplement the line regularization with a volumetric finite-core Euler closure while retaining the same K0–K14 acceptance protocol.
