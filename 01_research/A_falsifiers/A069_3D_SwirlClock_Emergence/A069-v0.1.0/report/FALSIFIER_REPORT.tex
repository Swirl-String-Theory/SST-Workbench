\section{Exact D1 analytical reference (not a vortex-particle model)}
Take an affine velocity $\mathbf u(\mathbf x,T)=A(T)\mathbf x$ with constant extensional strain $a$ and
\begin{equation}
A(T)=\begin{pmatrix}-a/2&-\Omega(T)&0\\\Omega(T)&-a/2&0\\0&0&a\end{pmatrix},\qquad
\Omega(T)=\Omega_0 e^{aT}.
\label{eq:affine}
\end{equation}
Then $\nabla\cdot\mathbf u=\operatorname{tr}A=0$, and the vorticity is $\bm\omega=\nabla\times\mathbf u=(0,0,2\Omega)$, which obeys $D\bm\omega/DT=(\bm\omega\cdot\nabla)\mathbf u$. The pressure Hessian
\begin{equation}
\nabla\nabla p=-\rho\operatorname{sym}(\dot A+A^2)
\label{eq:pressure}
\end{equation}
exactly balances Euler acceleration because $\operatorname{skew}(\dot A+A^2)=0$ when $\dot\Omega=a\Omega$. This example has infinite global energy on $\mathbb R^3$ and is only an exact \emph{local solver-control solution}, not a finite-energy vortex particle.

A material loop in the $z=0$ plane has
\begin{align}
R(T)&=R_0 e^{-aT/2}, & \Gamma&=\oint_{C(T)}\mathbf u\cdot d\mathbf\ell
=2\pi R(T)^2\Omega(T)=\mathrm{const},\label{eq:kelvin}\\
\Omega_{\mathrm{pred}}(T)&=\frac{\Gamma}{2\pi R(T)^2},&
\theta_{\mathrm{pred}}(T)&=\int_0^T\Omega(s)ds
=\Omega_0\frac{e^{aT}-1}{a}.\label{eq:phase}
\end{align}
At $a=0$ the continuous limit is $\Omega_0T$. All dimensional quantities have consistent dimensions: $[\Gamma]=\mathrm{m^2/s}$, $[\Omega]=[a]=\mathrm{s^{-1}}$, $[\theta]=1$. The actual executable uses dimensionless normalized numerical values. The phase \emph{measurement} integrates the Cartesian ODE $d\mathbf x/dT=A(T)\mathbf x$ with RK4/midpoint, then unwraps $\operatorname{atan2}(y,x)$. It is independent of equation~\eqref{eq:phase}'s value in the integrator.

For rigidly rotating reference coordinates, independently verify
\begin{equation}
\bm\omega_{\rm abs}=\bm\omega_{\rm rel}+2\bm\Omega_{\rm frame}.
\label{eq:frame}
\end{equation}
This is a frame identity; it does not imply that locally measured 3D vorticity is a scalar material invariant.
