\section{A029 closure-residual specific-Lagrangian kernel}
The A029 local finite-core state is a columnar incompressible Euler base flow
\[
\mathbf{v}_0=V(r)\,\mathbf e_\theta+U(r)\,\mathbf e_z,
\]
with perturbations proportional to
\[
\mathbf u'(r,\theta,z,t)=\epsilon V_0\,\Re\!\left[\widehat{\mathbf u}(r)
 e^{\lambda \widehat t+i(m\theta+\widehat k\widehat z)}\right],
\qquad
\frac{p'}{\rho_{\!f}}=\epsilon V_0^2\,\Re\!\left[\widehat\pi(r)
 e^{\lambda \widehat t+i(m\theta+\widehat k\widehat z)}\right].
\]
Here \(\widehat t=tV_0/a\), \(\lambda=\sigma-i\omega\), and \(a\) is the physical core radius.
For the material-parcel diagnostic
\[
\ell_{\rm eff}=\frac12|\mathbf v|^2-\frac{p}{\rho_{\!f}},
\]
the linear perturbation is
\[
\frac{\delta\ell^{(1)}}{V_0^2}
=\epsilon\,\Re\!\left[
\left(U\widehat u_z+V\widehat u_\theta-\widehat\pi\right)e^{\lambda\widehat t+i(m\theta+\widehat k\widehat z)}
\right].
\]
Along a base-flow material trajectory at fixed \(r\),
\[
\dot\theta=\frac{V(r)}{r},\qquad \dot{\widehat z}=U(r),
\]
so the relative material frequency is
\[
\omega_{\rm rel}(r)=\omega-\left[m\frac{V(r)}{r}+\widehat k U(r)\right].
\]
Define
\[
C_\ell(r)=U\widehat u_z+V\widehat u_\theta-\widehat\pi,
\qquad
\mathcal L(r,\widehat t)=C_\ell(r)e^{\sigma\widehat t-i\omega_{\rm rel}(r)\widehat t}.
\]
Using A029's symmetric closure null,
\[
\boxed{
\mathcal K_\ell=\mathcal L_{0}-\frac12\left(\mathcal L_{-}+\mathcal L_{+}\right)
}
\]
and therefore
\[
\boxed{
\delta\ell_{\rm SST}^{(1)}(t)
=\epsilon V_0^2\Re\!\left[e^{i\phi_0}\mathcal K_\ell(\widehat t)\right]
}.
\]
The specific-action residual is
\[
\boxed{
\delta s_{\rm SST}(t)=\epsilon aV_0
\int_0^{\widehat t}\Re\!\left[e^{i\phi_0}\mathcal K_\ell(\tau)\right]d\tau
}.
\]
