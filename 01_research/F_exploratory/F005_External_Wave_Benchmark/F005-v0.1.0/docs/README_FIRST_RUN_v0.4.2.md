# F005 External Wave Benchmark — v0.4.2 qualification patch

**Scope:** qualified DEVELOPMENT metrics on the robot-sloshing dataset, without opening the 49.9 GB `DATASET.zip` and without accessing TEST/OOD response arrays.

## Install in the EXISTING F005 instance

Extract this patch into:

`SST-Workbench/01_research/F_exploratory/F005_External_Wave_Benchmark/F005-v0.1.0/`

Do not delete or overwrite the previous `outputs/` subfolders. The patch creates `run_all_v042.cmd`, `data/f005_qualification_v0.4.2.py`, `tests/`, `docs/`, and `report/`.

- `data/f005_free_run_family_v0.4.1.py` installed without local edits.
- Previous local `outputs/f005_integrity_baseline_v0.3.0/audit_report.json`.

## What changed from v0.4.1

1. **P5c**: score all approximately 75,181 candidates generated by the *same fingerprint algorithm* as v0.4.1; no 15,000-pair scoring cap. This does NOT cover all ~48 million possible pairs. Publisher family IDs are unavailable.
2. **P6d**: score both the endpoint at each horizon and the **entire forecast path**, on 750 unchanged validation trajectories.
3. **P6e**: compare frozen ARX(2) against persistence, linear extrapolation, zero-equilibrium, and an unforced damped oscillator with v0.3 TRAIN-derived parameters. **The oscillator is not independently fitted from physical geometry.**
4. **P6f**: report only diagnostics of fixed-frequency phase and amplitude; signal windows too short/weak are flagged.
5. **P6g**: report an *input-only* possible-TRAIN-family overlap and rerun development scores on a screen-negative validation subgroup if nonempty. This is **not** a publisher-family-disjoint holdout, and does not unlock TEST/OOD.

## Interpretation

- A P6d improvement can be a real ability to predict *conditioned on the known future acceleration*. It is NOT a blind physical SST result and not forecasting the driving acceleration itself.
- The prior v0.4.1 15/15 wins were for **endpoint** RMSE versus only persistence and linear extrapolation. They do not guarantee v0.4.2 path or zero-baseline wins.
- CIs resample trajectories as though independent; these are descriptive because trajectory-family independence is not established.
- A successful run does **not** make P5c or P6g scientific PASS. P7 (Euler/PKLSA) and P8 (physical SST) remain unresolved.

Original ZIP archives, all previous releases, and the candidate split are left unchanged.
