# A042-v0.3.0 — Attosecond action bridge

## New dependency chain

The v0.2.0 primary closure remains untouched:

\[
\Gamma_{\rm fluid}/2
\stackrel{?}{=}
(h/m)_{\rm QGI}.
\]

v0.3.0 adds a downstream, target-blind bridge. If an SST producer supplies a **mass-specific action difference** \(\delta s_{\rm SST}\) with clean provenance, the QGI-derived specific quantum is reused as

\[
\left(\frac{\hbar}{m}\right)_{\rm QGI}
=\frac{1}{2\pi}\left(\frac{h}{m}\right)_{\rm QGI},
\]

and

\[
\boxed{
\delta\phi_{\rm SST}
=\frac{\delta s_{\rm SST}}{(\hbar/m)_{\rm QGI}}
}.
\]

This preserves the blind architecture: neither \(h\), \(\hbar\), particle mass, nor a CODATA target enters the new scorer.

## Prepared input contract

`data/attosecond/prepared/action_kernel_bundle.npz` must contain:

- `kernel_re[n_sample,n_t]`
- `kernel_im[n_sample,n_t]`
- `weights[n_t]`
- `delta_specific_action_m2_s[n_sample,n_t]`
- optional `energy_eV[n_sample]`, `theta_rad[n_sample]`, `delay_s[n_sample]`, `direction[n_sample]`

The matching `action_provenance.json` must declare `status=DERIVED_SPECIFIC_ACTION`, zero free phase-fit parameters, a frozen physical mapping to the orthodox kernel, and no upstream use of Planck/electron/Compton/alpha targets.

The package **does not synthesize missing attosecond data**. Missing inputs return `NOT_RUN`.

## Scientific boundary

The orthodox complex kernel must be generated by a gauge-consistent strong-field/photoionization pipeline. A042-v0.3.0 does not claim that adding \(\delta S/\hbar\) repairs or proves gauge invariance of an inconsistent SFA implementation.
