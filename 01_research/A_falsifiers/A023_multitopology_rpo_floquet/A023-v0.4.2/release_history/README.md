# Immutable release history

This directory contains exact ZIPs of all earlier releases needed to reconstruct the analysis lineage. `INDEX.sha256` is authoritative for byte-level verification.

v0.4.1 adds the exact v0.4.0 multi-topology ZIP while retaining v0.1.0, v0.1.1, v0.2.0 and v0.3.0 directly. The v0.4.0 ZIP itself also contains its historical chain.
