# Numerical checks with canonical SST constants

Using

\[
\mathbf{v}_{\!\boldsymbol{\circlearrowleft}}
=1.09384563\times10^6\ \mathrm{m\,s^{-1}},
\qquad c=299792458\ \mathrm{m\,s^{-1}},
\]

the illustrative clock factor is

\[
1-\sqrt{1-\mathbf{v}_{\!\boldsymbol{\circlearrowleft}}^2/c^2}
=6.656441447\times10^{-6}.
\]

Across \(18\,\mathrm{as}\),

\[
|\delta t|=1.19815946\times10^{-22}\ \mathrm{s}
=0.119816\ \mathrm{zs}.
\]

At \(E=100\,\mathrm{eV}\), using \(\delta\phi=E\delta t/\hbar\),

\[
|\delta\phi|\approx1.8203\times10^{-5}\ \mathrm{rad}.
\]

This is only a **scale diagnostic**. A constant phase is intensity-null, so this number is not itself an attosecond prediction. A physically useful SST signal requires a derived relative phase dependence on integration time, channel, energy, direction, topology, or another coherent degree of freedom.
