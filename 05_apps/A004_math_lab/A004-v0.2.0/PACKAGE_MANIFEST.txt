SST Math Lab v0.2.0
===================

Launchers
---------
run.cmd                 First-run dependency install if needed; opens index.html directly.
run_all.cmd             Dependency install + local Python HTTP server start.
run_server.cmd          Local HTTP server mode.
run_selftest.cmd        Optional Node.js core smoke test.
install_libs.cmd        Windows wrapper for dependency installer.
install_libs.ps1        Downloads six pinned JavaScript libraries to lib/.

Application
-----------
index.html              Main browser UI.
css/app.css             Responsive dark workbench layout.

js/vector.js            3-vector primitives.
js/geometry.js          Closed-curve cleanup, arclength resampling, curvature, torsion.
js/diagnostics.js       Exploratory SST mapping, Kelvin/LIA, FD spectral sanity gate.
js/physics.js           Finite-core Biot-Savart, pressure-Poisson, transport frame, stability Jacobian.

js/batch.js             Multi-file/folder batch analysis.
js/plots.js             Plotly visualizations.

data/sample_trefoil.xyz   Sample centerline.
lib/README.txt             Dependency-location note; libraries install here on first run.

tests/core_smoke_node.js  Dependency-free Node smoke test for geometry + finite-core physics.

Important scientific status
---------------------------
The reduced stability eigenspectrum is an instantaneous frozen-geometry finite-core
Biot-Savart linearization in a holonomy-distributed normal/binormal mode basis.
It is not yet an RPO/Floquet monodromy calculation.
