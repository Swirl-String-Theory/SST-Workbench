Native pybind11 status
----------------------
The actual Windows .pyd for v0.4.1 must be rebuilt and certified on the target machine:

  python -m pip install -r requirements.txt
  python -m fermat_ext.build_ext_if_needed --force --strict
  python run_all_checks.py --out-dir audit_out_native --no-auto-build --require-native

The required target-machine gates are:

  field native/Python parity Linf < 1e-12
  Jacobian native/Python parity Linf < 1e-10
  radial native/Python parity < 1e-10

The native API was introduced in v0.4.0. A v0.3 .pyd is API-incomplete and must
not be reused. Rebuilding is also recommended when replacing any v0.4.x source tree.

Epistemic status
----------------
Raw stationary roots are labelled RESOLVED_LOCAL_MINIMUM, not certified. Only
branches passing the explicit multi-resolution convergence gates receive weak or
strong certification labels. The package does not certify a global closed Fermat
geodesic, a physical photon sphere, or a QSM pole. All generated results preserve:

  global_closed_orbit_certified = false
  qsm_certified = false
