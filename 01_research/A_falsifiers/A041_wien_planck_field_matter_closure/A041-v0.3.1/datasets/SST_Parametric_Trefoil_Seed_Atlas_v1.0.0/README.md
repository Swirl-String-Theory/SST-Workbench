# SST Parametric Trefoil Seed Atlas v1.0.0 (PTSA)

Canonical dataset name for the 48-candidate analytic `track_trefoil` family formerly referred to informally as the "shader-derived set".

The name deliberately describes the mathematics rather than the rendering platform that inspired the extraction. The atlas contains **no Shadertoy source code, renderer, or SDF code**. It is generated by an independent implementation of the anisotropic torus-knot family

\[
X(t)=U[R+a\cos(3t)]\cos(2t)+V[R+a\cos(3t)]\sin(2t)+N[b\sin(3t)+z_0].
\]

Parameter grid: 3 values of `baseR` × 4 values of radial bulge `a` × 4 values of axial weave `b` = **48 candidates**. Candidate filenames are parameter-opaque SHA-256-derived IDs. `ATLAS_PUBLIC_MANIFEST.json` contains geometry hashes but no shape parameters. The parameter mapping is kept under `reveal_only/` and is never consumed by the blind action scorer.

The atlas is geometry-only. `T(2,3)` is an expected construction label, not a standalone topology certification result.
