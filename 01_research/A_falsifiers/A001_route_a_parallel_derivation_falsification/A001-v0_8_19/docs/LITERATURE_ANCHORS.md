# Literature anchors

This pack uses the following external anchors conceptually:

- Onsager point-vortex gas and 2D vortex statistical mechanics.
- Berezinskii--Kosterlitz--Thouless vortex-pair/fugacity logic.
- Crofton/stereology/integral geometry for line-intersection factors.
- Weyl-law / heat-kernel phase-space counting for torsion-channel estimates.

The pack does not claim these sources derive SST. They motivate the model families and, in the Crofton case, the projection factor.
