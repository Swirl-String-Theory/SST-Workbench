\section{Resolved smooth vorticity-tube candidate}
For each closed smooth or piecewise-smooth curve $\gamma$ and Gaussian width $a>0$, define
\begin{equation}
\boldsymbol{\omega}_a(\mathbf{x}) =
\Gamma \oint_\gamma d\mathbf{X}\,
\frac{\exp[-|\mathbf{x}-\mathbf{X}|^2/(2a^2)]}{(2\pi a^2)^{3/2}}.
\end{equation}
This is a three-dimensional smooth, finite-width vorticity distribution; its divergence vanishes exactly for a closed curve because the derivative along the curve is a total derivative. It need not be a stationary Euler or Navier--Stokes solution.

The compatible free-space kinetic energy for constant ambient density is
\begin{equation}
E_a=\frac{\rho_f\Gamma^2}{8\pi}\oint_\gamma\oint_\gamma
\frac{\operatorname{erf}(|\mathbf{X}-\mathbf{Y}|/(2a))}
{|\mathbf{X}-\mathbf{Y}|}\,d\mathbf{X}\cdot d\mathbf{Y}.
\end{equation}
The finite diagonal limit is $1/(a\sqrt\pi)$. This kernel avoids arbitrary grid-cell cutoff and supports independent C++/Python quadrature. Only ambient density $\rho_f$ enters $E_a$. Substituting the much larger $\rho_{\mathrm{core}}$ into the whole bath is \emph{not a valid physical inference}.

For a diagnostic physical length, the code reports $L_{\mathrm{phys}}=r_c/a_{\mathrm{normalized}}$; this \emph{assumes} $a_{\mathrm{core}}=r_c$, whereas SST Canon v0.8.35 distinguishes the two. SI energy and mass under that scale hypothesis must not be reported as a derived electron mass.
