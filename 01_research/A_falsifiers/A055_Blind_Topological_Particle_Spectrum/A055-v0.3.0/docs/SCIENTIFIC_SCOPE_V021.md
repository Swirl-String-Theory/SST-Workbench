# A055 v0.2.1 scientific scope

v0.2.1 tests whether independently qualified knot geometries support reproducible, source-independent dimensionless vortex-dynamic spectra under the existing C006 regularized Biot–Savart closure.

A PASS establishes numerical reproducibility under that closure. It does not establish Standard-Model identity.

The major methodological advance over v0.1.x is that the particle-spectrum features are no longer extracted from arbitrary PD-screening embeddings. Geometry authority is moved upstream to E010/E011 provider-qualified source data, and dynamics is delegated to the already maintained C006 kernel.

True Floquet evidence is conditional on an accepted relative periodic orbit and uses C006's nonlinear relative-return monodromy. The local-generator multiplier analogy is not accepted as true Floquet evidence.

Multi-component link dynamics remains outside v0.2.1.
