# Bundled Fourier fixtures

This pack includes only four small `.fseries` carrier fixtures needed for the twist-knot stratum:

- `knot.4_1.fseries` — figure-eight knot;
- `knot.5_2.fseries` — three-twist knot;
- `knot.6_1.fseries` — stevedore knot;
- `knot.7_2.fseries`.

They are copied from the Fremlin Fourier-series dataset supplied for the SST/VortexLab workbench. The v0.1.0 source-qualification scan excludes comments containing `must be checked`, `converted to 6-column`, `Data source: Brian Gilbert`, or `Fourier projection` from primary use. The user-modified `9_1`/`10_1`-style converted files are therefore not part of this pack.
