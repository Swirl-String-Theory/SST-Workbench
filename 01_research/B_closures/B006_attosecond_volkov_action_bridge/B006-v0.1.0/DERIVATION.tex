\section{Attosecond Volkov--Action measurement bridge}
\label{sec:attosecond-volkov-action-bridge}

\subsection{Orthodox amplitude}
For an angle-resolved attosecond streaking measurement, write the orthodox strong-field amplitude schematically as
\begin{equation}
M_0(\mathbf p,\tau)
 =\int K_0(t;\mathbf p,\tau)\,dt,
\end{equation}
where the kernel contains the transition matrix element, the XUV field and the orthodox Volkov phase. This notation preserves the structure used by Gao et al. while isolating the proposed SST modification from the orthodox photoionization calculation \cite{Gao2026Attosecond,Keathley2016VTGPA}.

\subsection{Action-to-phase interface}
Let an SST calculation independently produce a trajectory- or channel-dependent action difference \(\delta S_{\rm SST}\). The bridge hypothesis is
\begin{equation}
\boxed{\delta\phi_{\rm SST}=\frac{\delta S_{\rm SST}}{\hbar}}.
\end{equation}
Dimensionally, \([\delta S]=[\hbar]=\mathrm{J\,s}\), so \(\delta\phi\) is dimensionless.

For a provenance-clean mass-specific branch, define \(\delta s=\delta S/m\). Then
\begin{equation}
\boxed{
\delta\phi_{\rm SST}
=\frac{\delta s_{\rm SST}}{\hbar/m}
},
\qquad
[\delta s]=[\hbar/m]=\mathrm{m^2\,s^{-1}}.
\end{equation}
This form can use an independently measured \((\hbar/m)\) and therefore need not expose a CODATA Planck target to a blind scorer.

\subsection{Fluid-to-action producer boundary}
For a material parcel moving in a prescribed pressure field of a constant-density incompressible Euler solution, an effective trajectory diagnostic can be written
\begin{equation}
\ell_{\rm eff}=\frac12|\mathbf v|^2-\frac{p}{\rho_{\!f}},
\qquad
[\ell_{\rm eff}]=\mathrm{m^2\,s^{-2}}.
\end{equation}
A candidate-minus-reference difference gives
\begin{equation}
\delta s_{\rm eff}(t)
=\int_{t_0}^{t}
\left[
\frac12\left(|\mathbf v_1|^2-|\mathbf v_0|^2\right)
-\frac{p_1-p_0}{\rho_{\!f}}
\right]dt'.
\end{equation}
Hence \([\delta s_{\rm eff}]=\mathrm{m^2\,s^{-1}}\). This construction is a material-trajectory diagnostic in a solved pressure field; it is not identified here with the complete constrained Euler-field action. The additional SST hypothesis is that an independently justified action difference of this type is the phase-producing quantity entering the measurement bridge. Hamiltonian/variational formulations of ideal fluids require the incompressibility and relabeling constraints to be treated consistently \cite{Salmon1988Hamiltonian}.

\subsection{Exact and perturbative observables}
The modified amplitude is
\begin{equation}
M_{\rm SST}(\mathbf p,\tau)
=\int K_0(t;\mathbf p,\tau)
\exp\!\left[i\delta\phi_{\rm SST}(t;\mathbf p,\tau)\right]dt.
\end{equation}
If \(|\delta\phi|\ll1\),
\begin{align}
M_{\rm SST}&=M_0+\delta M+O(\delta\phi^2),\\
\delta M&=i\int K_0(t)\delta\phi_{\rm SST}(t)\,dt.
\end{align}
With \(I=|M|^2\),
\begin{equation}
\boxed{
\delta I
=2\operatorname{Re}\!\left[M_0^*\delta M\right]
+O(\delta\phi^2)
}.
\end{equation}

\subsection{Global-phase null theorem}
If \(\delta\phi_{\rm SST}(t)=\phi_0\) is constant over the coherent integration coordinate,
\begin{equation}
M_{\rm SST}=e^{i\phi_0}M_0,
\end{equation}
and therefore
\begin{equation}
\boxed{|M_{\rm SST}|^2=|M_0|^2}.
\end{equation}
Thus a uniform SST clock phase cannot by itself alter a streaking intensity. The measurable candidate must contain relative phase structure or couple coherent channels.

\subsection{Directional residual}
For opposite momentum hemispheres define
\begin{equation}
A_{\pm}(E,\tau)=
\frac{I_+(E,\tau)-I_-(E,\tau)}
{I_+(E,\tau)+I_-(E,\tau)}.
\end{equation}
The SST-facing observable is not \(A_{\pm}\) itself but
\begin{equation}
\boxed{
\Delta A_{\pm}
=A_{\pm}^{\rm data}-A_{\pm}^{\rm orthodox}
}.
\end{equation}
This subtraction is mandatory because standard attosecond streaking already produces direction-dependent momentum shifts \cite{Gao2026Attosecond}.

\subsection{Falsifiability conditions}
A candidate reaches the experimental layer only if (i) \(\delta S_{\rm SST}\) is derived without fitting an arbitrary phase map to the same streaking data, (ii) its units and provenance are explicit, (iii) a factorable global phase is removed, (iv) the orthodox kernel includes known chirp, propagation, phase-matching and detector effects, and (v) the exact forward prediction is frozen before comparison with held-out data.
