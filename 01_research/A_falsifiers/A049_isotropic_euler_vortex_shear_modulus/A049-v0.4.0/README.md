# A049 — Isotropic Euler-Vortex Shear-Modulus Falsifier v0.4.1

**Research question:** can an isotropic incompressible Euler-vortex microstructure generate a non-zero conservative transverse rigidity and, more stringently, a qualified bulk transverse wave pole whose speed is measured dynamically rather than inferred from a static modulus?

v0.4.1 is a qualification/portability upgrade of v0.4.0. It keeps all Master-Factor and proton/electron targets reveal-only and adds a new prerequisite: the structured Euler background must first be shown to be sufficiently close to a translating relative equilibrium before a propagating pole may be interpreted physically.

## New in v0.4.1

- MSVC-safe C++17 native kernel: `M_PI` is replaced by an internal `constexpr double kPi`, so Visual Studio `/std:c++17` no longer depends on non-standard math macros.
- Native build smoke import after compilation.
- Relative-equilibrium translation fit. For the Euler RHS `R(u)`, v0.4.1 fits the uniform drift velocity `U` minimizing

  `|| R(u) + U·grad(u) ||_2`.

  A travelling relative equilibrium should have a small normalized residual.
- Short co-moving evolution test: the measured Euler evolution is compared with the exact Fourier translation generated by the fitted drift.
- Higher-resolution relative-equilibrium check at a separately configured grid size.
- Long-window frozen-background tangent diagnostic. This asks whether the instantaneous linearized operator contains a coherent transverse oscillatory pole even when the physical base state itself is not stationary.
- Explicit precondition gates separate numerical qualification from physical interpretability.

## Blindness

The blind configuration contains no `c`, `alpha`, proton/electron mass ratio, Master-Factor target, or target `chi`. The blind observable remains

`chi_wave = c_T / v_ref`

and is only emitted as a hierarchy candidate after a dynamically measured bulk pole passes the wave and relative-equilibrium preconditions.

## Interpretation logic

A numerically stable Euler run is not sufficient. If the structured background is not close to a relative equilibrium, v0.4.1 returns an **inconclusive background** status rather than interpreting probe decoherence as evidence against a bulk wave sector. Frozen-background results are diagnostic only and cannot promote a failed evolving-background result.
