Native pybind11 status
----------------------
The artifact environment does not contain pybind11, so the actual Python
extension could not be built here. The C++ kernel itself compiled and passed.
The native Windows release gate must be run on the target machine:

  python -m pip install -r requirements.txt
  python -m fermat_ext.build_ext_if_needed --force --strict
  python run_all_checks.py --out-dir audit_out_native --no-auto-build --require-native
