# Legacy template policy

For new SST falsifiers, the following are superseded by `SST_Falsifier_Framework_v1.0.6`:

- `SST_Blind_MultiLibrary_Falsifier_Template_v0.1.0`
- `SST_cpp_pybind_audit_template`
- `SST_GPU_SYCL_DPC_audit_template`
- framework v1.0.0 through v1.0.5 development/candidate lines

Do not delete historical templates or framework releases that are needed to reproduce old falsifiers. Mark them `LEGACY_REFERENCE_ONLY` and keep existing falsifier pins unchanged. All new falsifiers use v1.0.6 unless a later canonical framework explicitly supersedes it.
