# Target-free trefoil shape ratio

For a torus-like trefoil \(T(2,3)\), the projected toroidal azimuth obeys approximately \(\theta\simeq 2t\).  After rigid alignment, the code estimates a PCA torus axis, unwraps \(\theta\), defines \(t=\theta/2\), and measures the poloidal \(m=3\) Fourier amplitudes

\[
R_{\rm radial}=2\left|\left\langle (\rho-\langle\rho\rangle)e^{-i3t}\right\rangle\right|,
\qquad
r_{\rm axial}=2\left|\left\langle (z-\langle z\rangle)e^{-i3t}\right\rangle\right|,
\]

so that

\[
\chi_{\rm eff}=R_{\rm radial}/r_{\rm axial}.
\]

The observable is dimensionless, invariant to translation, rotation and uniform scaling, and is excluded from all discovery scores and promotion gates.  It is intended for post-ranking dynamical-attractor analysis only.
