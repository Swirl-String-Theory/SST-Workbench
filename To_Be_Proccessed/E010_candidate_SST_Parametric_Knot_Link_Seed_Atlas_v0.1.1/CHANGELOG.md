# PKLSA changelog

## v0.1.1

Packaging-only portability correction; all 2352 candidate geometry bundles and candidate IDs are unchanged from v0.1.0.

- Removed Python `__pycache__/*.pyc` records from the signed package manifest.
- `tools/verify_atlas.py` explicitly treats interpreter-generated bytecode as runtime cache, never as a portable atlas artifact.
- Fixes verification across Python 3.13/3.14 and other interpreter versions.
- No topology family, parameter grid, coordinates, or candidate ranking data changed.
