% SST-REPORT-SECTION:IDENTIFICATION
\section{Identification}
A058 v0.2.2 is a single-trefoil, seven-slider, default-relative KnotPlot response experiment with adaptive convergence rather than a fixed relaxation count.
% SST-REPORT-SECTION:QUESTION
\section{Question}
Which anonymous GUI slider parameters alter the adaptively converged embedded geometry, bead parametrization, or convergence time relative to their runtime default values?
% SST-REPORT-SECTION:HYPOTHESES
\section{Hypotheses}
The frozen science contract registers the global no-effect null and measurable-response alternative.
% SST-REPORT-SECTION:ASSUMPTIONS
\section{Assumptions}
The actual executable parameter dump defines numerical defaults. The documented reset dynamics are damped; collision-fast is used for collision avoidance. No fit-to-distance, close, maximum-displacement, splitting, display-step, or time-increment override is permitted.
% SST-REPORT-SECTION:SYMBOLS
\section{Symbols}
Primary quantities are multiplier $m$, $x=\log_2m$, normalized shape distance $D_{\rm shape}$, edge-spacing coefficient of variation, and iterations-to-convergence $N_{\rm conv}$.
% SST-REPORT-SECTION:EQUATIONS
\section{Equations}
Registered equations and dimensional checks are generated from the frozen science contract.
% SST-REPORT-SECTION:ALGORITHM
\section{Algorithm}
Install calibration verifies seven setters and five force-sector toggles and exports exactly one trefoil. The production campaign contains five sector references and seven one-slider-at-a-time sweeps. Each condition is advanced in small $\mathrm{go}$ quanta in one persistent KnotPlot process until four consecutive shape/scalar windows satisfy the plateau thresholds or the preregistered safety cap is reached.
% SST-REPORT-SECTION:SOURCES
\section{Sources}
One runtime-identified KnotPlot executable and one catalogue trefoil define the simulation source family. Conditions are perturbations, not independent replicates.
% SST-REPORT-SECTION:GATES
\section{Gates}
G0--G9 retain Framework-v1.0.6 lane semantics. Numerical failures are recorded and the campaign continues where possible so diagnostic structure is retained.
% SST-REPORT-SECTION:NUMERICS
\section{Numerics}
Positive multipliers are $2^{k/4}$, $k=-16,\ldots,16$, with a separate zero endpoint. There is no fixed final relaxation count. A 32-iteration command quantum is an observation cadence only; the stopping decision is adaptive.

\section{Interpretation}
A slider may affect parametrization or convergence time without selecting a different final embedded curve. Conversely, persistent final-shape changes identify a geometry-selecting numerical control in this KnotPlot model. None of these outcomes establishes physical vortex stability by itself.
