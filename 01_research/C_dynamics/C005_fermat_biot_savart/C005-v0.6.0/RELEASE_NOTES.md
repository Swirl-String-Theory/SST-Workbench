# v0.6.0 — Axial hole-bundle coupling research release

Adds a divergence-free coaxial central-flux plus opposite-return-flux background in a periodic axial computational cell, analytic field/Jacobian evaluation, rigid-motion shape-residual fitting, a trefoil bundle parameter sweep, and the dimensionally explicit circulation → vorticity → angular-rate → phase-clock chain.

The analytic bundle is a finite-radius, not finite-length, model. A physically closed finite racetrack-bundle discretization remains a separate gate and is not claimed here.
