# Triple gear stratum

The built-in `TRIPLE_GEAR_T3_3` is a hydrodynamic/topological proxy: the `T(3,3)` torus link consists of three components, each individually an unknot, with a common central toroidal aperture. A helical closed thread bundle is passed through this common aperture.

The package deliberately does **not** model printed gear teeth, contact forces, elasticity, or a prescribed transmission ratio. Any mechanical helix/ring ratio belongs only to post-reveal comparison and cannot enter blind acceptance.
