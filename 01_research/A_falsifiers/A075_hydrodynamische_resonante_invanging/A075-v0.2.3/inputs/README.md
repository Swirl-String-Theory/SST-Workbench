# Geometry admission: fail-closed

The analytic 0_1 circle and analytic T(2,3) trefoil 3_1 are reproducible code initializers; the trefoil is **not** claimed to be the ideal or PKLSA seed. Geometry is not artificially kept circular once the Euler solver evolves.

For canonical twist-knot geometry put the *unchanged original bytes* here:
- `KNOT_5_2_N2048_ORIG.xyz`
- `KNOT_6_1_N2048_ORIG.xyz`

Files must have three numeric XYZ columns (comment lines `#` allowed). The reader calculates SHA-256 from the original bytes, checks finite and nondegenerate coordinates and arclength-resamples with a declared scale; topology certification, embedding source license and finite-core admissibility remain independent qualification tasks. Missing files block their case; the software never invents a topology.

The incoming unknot and receiver unknot pair form a three-vorticity-object test. For the `3_1`, `5_2` and `6_1` branches, the second receiver object is changed to that knot while the other receiver and donor remain unknots. This is not evidence of a physically selected atomic structure.
