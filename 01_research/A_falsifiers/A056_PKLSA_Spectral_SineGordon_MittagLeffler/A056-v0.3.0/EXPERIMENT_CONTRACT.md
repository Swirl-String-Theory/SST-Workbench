# A056-v0.3.0 dynamic experiment contract

Each blind case is `A056-DYNAMIC-PROVIDER-5` with arrays `t`, `s`, `phi`, `ringdown_t`, `ringdown`. Real provider cases must additionally declare opaque source group, independence/provenance family, upstream geometry/raw hashes, solver/perturbation IDs, `provider_case_family`, resolution value/unit and `provider_numerically_valid=true`.

The preregistered real-provider phase is `paired_kelvin_residual_phase_v1`; the preregistered mode envelope is `paired_kelvin_mode_envelope_v1`. No alternative frame, mode number, alignment, baseline subtraction or phase definition may be selected after SG/ML outcomes are inspected.
