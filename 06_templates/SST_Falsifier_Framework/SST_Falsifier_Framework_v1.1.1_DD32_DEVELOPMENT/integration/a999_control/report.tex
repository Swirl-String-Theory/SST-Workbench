\section{Identification, scope, status}
This document preregisters the A999 template-integration control. The sole purpose is to verify E010 v0.4.0 geometry intake, a local self-contained runtime, independent execution records from Python, native C++/pybind11, and one chosen graphics processor (Intel XPU by default, optional NVIDIA CUDA), numerical comparisons, automatic reporting, and immutable packaging. A technical PASS is not an SST physical claim. The frozen \texttt{CONTROL\_PIN.json} pins the exact source record and export manifest. No physical SI calibration exists.
% SST-REPORT-SECTION:QUESTION
\section{Research question and objective}
Can a verified single-component historical E010 seed, with a fixed periodic-midpoint Biot--Savart discretization and fixed query locations, produce mutually consistent observables through at least two independently executed implementation categories? This is a software validation question, not a test of fluid equilibrium or knot stability.
% SST-REPORT-SECTION:HYPOTHESES
\section{Null and alternative hypotheses}
Null $H_0$: at least one demanded implementation is unavailable, produces incompatible outputs, changes the pinned input identity, or exceeds its parity threshold. Alternative $H_1$: Python executes plus at least one additional implementation and each executed independent backend meets the appropriate relative error bound. Passing $H_1$ does not reject a hydrodynamic physical null hypothesis. Missing hardware is UNRESOLVED rather than a physical FAIL.
% SST-REPORT-SECTION:ASSUMPTIONS
\section{Assumptions and limits}
This is a static one-filament calculation in the native numerical coordinate system. It assumes closed periodic indexing and uses eight query positions away from the nominal string. The displayed data originate from one historical source record, not independent geometry providers. The 512 vertices or other exported resolution are accepted as represented; neither isotopy nor convergence has been checked. A changed mesh, radius or scale requires a new control version.

\section{Mathematical operator and observables}
The exact discrete operator is the fixed periodic-midpoint regularized Biot--Savart formula
\begin{equation}
\mathbf{v}(\mathbf{q})=\frac{\Gamma}{4\pi}\sum_{j=0}^{N-1}
\frac{(\mathbf{x}_{j+1}-\mathbf{x}_{j})\times
[\mathbf{q}-\frac{1}{2}(\mathbf{x}_{j}+\mathbf{x}_{j+1})]}
{\left(\left\|\mathbf{q}-\frac{1}{2}(\mathbf{x}_{j}+\mathbf{x}_{j+1})\right\|^2+a^2\right)^{3/2}},\qquad \mathbf{x}_N=\mathbf{x}_0.
\label{eq:E1}
\end{equation}
The numerical comparison uses
\begin{equation}
\epsilon_b=\frac{\|\mathbf{V}_b-\mathbf{V}_{\mathrm{Py64}}\|_2}{\|\mathbf{V}_{\mathrm{Py64}}\|_2},\qquad
\mathbf{V}_b\in\mathbb{R}^{24};\quad \|\mathbf{V}_{\mathrm{Py64}}\|_2>10^{-30}.
\label{eq:E2}
\end{equation}

\section{Interpretation, falsifiers and minimal follow-up}
A G10 PASS is only evidence that the chosen software paths performed the same discretized numerical calculation within registered tolerances. G10 FAIL identifies a numerical discrepancy requiring independent debugging. Missing hardware or an invalid source pin yields UNRESOLVED. This test cannot establish finite-core convergence, dynamical self-confinement, trefoil equilibrium, physical source independence, SI calibration, or conservation of fluid invariants. A true physical falsifier requires separate preregistered hypotheses, a time integrator, spatial and temporal convergence, and independent controls.
