# Changelog

## v0.3.2
- Supersedes the unexecuted/packaging-defective v0.3.1 diagnostic path with a clean v0.3.0-based release.
- Freezes the observed v0.3.0 blind result hash as explicit parent evidence; the v0.3.0 verdict remains immutable.
- Separates branch identity retention from the inherited stationary persistence `pass` flag.
- Adds checkpoint-majority branch selection with no fixed target mode.
- Adds full-horizon phase-path analysis with explicit angular-rate units \(\omega=d\phi/dt\) and cycle-rate conversion \(f=\omega/(2\pi)\).
- Adds `COHERENT_REVERSING` so a smooth sign change in angular phase rate is not automatically treated as incoherence.
- Adds stationary, drifting, reversing, complex-coherent, and unresolved phase classes using eight fixed local segments, quadratic-vs-linear BIC, and piecewise normalized RMSE.
- Adds focused 32-carrier modal/phase campaign; pressure-memory/spatial/divergence results are inherited only as frozen parent evidence rather than rerun.
- Adds synthetic stationary/chirp/reversal/random-phase tests and a regression test proving branch retention is independent of the parent persistence pass.

## v0.3.0

- Preserves v0.2.2/v0.2.3 results as immutable parent evidence.
