# Audit of the submitted v0.2.0-labelled Windows output set

Audit date: 2026-08-30.

## Native/runtime result

The submitted output set reports:

- Windows 11 / CPython 3.13.9 / NumPy 2.5.2;
- native pybind backend imported from a Windows `.pyd`;
- OpenMP enabled;
- KAtlas snapshot SHA-256 verified;
- blind campaign 48/48 geometry hashes valid;
- byte-exact reveal commitment valid.

## Release identity mismatch

The directory/output set is labelled `SST_Knot_Library_v0.2.0`, but both
`runtime_validation.json` and `reference_validation.json` report library version `0.2.1`.
The submitted local integrity report is internally valid for that local tree, but it is not the
same byte set as the published v0.2.0 archive used for comparison during this audit:

- 15 files shared by both trees have different SHA-256 hashes;
- 4 additional files are present in the submitted tree;
- no files from the published v0.2.0 manifest are missing.

Therefore the numerical output is usable as a test result, but it must not be cited as an exact
reproduction of the published v0.2.0 artifact. v0.2.2 adds an explicit release-identity gate.

## Dataset scan

Submitted inventory: 54 files.

- 49 coordinate assets loaded successfully;
- 4 Brian Gilbert `*_AB.txt` Fourier records were rejected by the old XYZ-only path;
- `0TwelveData.csv` was rejected although it is summary metadata, not a centerline.

v0.2.2 adds a documented Brian-Gilbert Fourier decoder and classifies the TwelveData summary CSV
as `SKIPPED_METADATA`.

## Topology namespace defect

The old filename parser used a generic `crossing.index` pattern. This caused 18 false topology
hints in the submitted inventory:

- 12 multi-component `link_<crossings>.<components>.<index>` files were labelled as knots;
- 6 `torus_<p>.<q>` files were labelled as Alexander-Briggs/Rolfsen knots.

v0.2.2 uses disjoint namespaces:

- knots: `3_1`, `6_2`, ...;
- links: `L4_2_1`, `L6_3_2`, ...;
- torus families: `T(2,3)`, `T(6,15)`, ... .

Filename inference remains an *expected-topology hint*, never a certification.
