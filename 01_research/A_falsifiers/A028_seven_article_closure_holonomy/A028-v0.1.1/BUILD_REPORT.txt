Important environment note:
The validation container had no outbound package network and no standalone
pybind11 Python package. The native source was therefore compiled manually
against pybind11 headers already present in the host. The shipped Windows
installer uses requirements.txt + pybind11.setup_helpers as intended.

No real user KnotPlot/Ridgerunner dataset was available in the execution
container, so no claim is made that physical SST gates pass on real knots.
Static centerline-only real runs are expected to produce INDETERMINATE for
phase, pressure, probe and representation gates until independent sidecars
are supplied.

v0.1.1 repair note
------------------
The v0.1.0 Windows/MSVC run exposed a portability bug in cpp/native.cpp: POSIX
ssize_t was used as an index type. MSVC does not define ssize_t. v0.1.1 uses
standard C++17 std::ptrdiff_t and hardens the build/import path. OpenMP is still
preferred, with a serial native fallback if the toolchain lacks OpenMP support.
